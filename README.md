# NỘI THẤT HOME

## 1. Giới thiệu

NỘI THẤT HOME là website bán đồ nội thất được xây dựng nhằm hỗ trợ khách hàng tìm kiếm, lựa chọn và đặt mua sản phẩm trực tuyến.

Hệ thống đồng thời cung cấp các chức năng quản trị sản phẩm, khách hàng, đơn hàng, doanh thu và đánh giá sản phẩm.

## 2. Công nghệ sử dụng

- **Frontend:** HTML, CSS, JavaScript, EJS.
- **Backend:** Node.js, Express.js.
- **Cơ sở dữ liệu:** Microsoft SQL Server.
- **Công cụ phát triển:** Visual Studio Code, SQL Server Management Studio.
- **Quản lý mã nguồn:** Git và GitHub.

## 3. Chức năng chính

### Khách hàng
- Xem danh sách và chi tiết sản phẩm.
- Tìm kiếm, lọc, sắp xếp và phân trang.
- Đăng ký, đăng nhập và đăng xuất.
- Quản lý giỏ hàng.
- Đặt hàng và theo dõi trạng thái đơn.
- Yêu cầu hủy đơn hàng.
- Đánh giá sản phẩm.

### Quản trị viên
- Quản lý sản phẩm.
- Quản lý khách hàng.
- Quản lý đơn hàng và trạng thái thanh toán.
- Xử lý yêu cầu hủy đơn.
- Xem thống kê và biểu đồ doanh thu.
- Duyệt và xóa đánh giá sản phẩm.

## 4. Hướng dẫn cài đặt

**Bước 1:** Cài đặt Node.js và Microsoft SQL Server.

**Bước 2:** Tải source code về máy.

**Bước 3:** Mở thư mục dự án bằng VS Code.

**Bước 4:** Cài đặt thư viện:

```bash
npm install
```

**Bước 5:** Tạo cơ sở dữ liệu `NoiThatDB` từ bản sao lưu hoặc script SQL được cung cấp riêng.

**Bước 6:** Cấu hình kết nối SQL Server và các biến môi trường cần thiết.

**Bước 7:** Chạy website:

```bash
node app.js
```

**Bước 8:** Truy cập:

http://localhost:3000

## 5. Mục đích đồ án

Xây dựng một hệ thống thương mại điện tử nội thất cơ bản, giúp khách hàng mua sắm thuận tiện và hỗ trợ người quản trị quản lý hoạt động kinh doanh.

## 6. Ghi chú

Đây là sản phẩm phục vụ học tập và trình bày đồ án. Một số chức năng có thể cần tiếp tục hoàn thiện trước khi triển khai thương mại thực tế.
